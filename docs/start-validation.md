# Shared start screen

The production root uses StartScreen for arena entry: title, name and two team buttons, or one Play button for saved teams. Validation and reproduction: [cutover-validation.md](cutover-validation.md). The component and arena entry tests cover draft retention after refusal, fixed accepted names, legacy team selection, authoritative team correction, touch attribution and one-use automatic resume.
